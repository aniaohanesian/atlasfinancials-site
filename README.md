# atlasfinancials.io

The public landing page for Atlas, served by GitHub Pages at https://atlasfinancials.io.

It is one self-contained file. `index.html` holds the markup, the CSS and the JavaScript,
so there is nothing to build and nothing to install. Edit it, commit, push, and the live
site updates within a minute or two.

| File | What it is |
|---|---|
| `index.html` | The whole page. |
| `assets/` | The Atlas logo, navy and white. |
| `CNAME` | Tells GitHub Pages the domain is `atlasfinancials.io`. Do not delete it. |
| `convert.ico` | The little icon in the browser tab. |
| `headshot.JPG` | Photo, not used on the current page. |
